# 曲库节拍驱动灯光（0.1.3-dev）

## 正确的选歌位置

**在曲库加载/播放当前曲目，舞台页面不再要求另选播放歌曲。**

舞台 → Live 舞台灯光（实验）新增两种明确区分的方式：

1. **通用灯光 · 跟随曲库节拍**：自动使用当前已加载曲目的 BPM / 拍点，驱动当前舞台可用的 Light / VLB。无需原生模板目录，颜色与强度仍可调整。这是程序化效果，不是游戏原曲的专属灯控。
2. **原生模板 · 跟随曲库节拍**：默认“自动（匹配当前舞台）”，在目录中寻找环境资源完全匹配的模板，优先 TrueEnd。复用该模板的原生设备轨、BPM 轨与灯控编排，并按曲库曲目的拍数重定时。没有匹配模板时保持待机，不借用别的舞台或偷偷降级。

手动选择“原生灯光模板”只改变灯控来源，不切换曲库音频、外部动作或相机；此时重新进入摄影才会载入模板配套舞台。刷新原生模板不是刷新外部曲库。自动选择时不会把当前舞台强行换成 Agitato。

仅当舞台灯光开关开启、未启用自定义节点控制且处于已有的已验证摄影作用域时驱动设备。现有普通染色/呼吸/渐变模式保持不变。

## BPM 和首拍来源

按**已加载曲目的目录和加载代数**绑定结果，不使用曲库列表中仅高亮、尚未加载的另一首曲目。

- 优先读取该曲目已有 `info.json` 的数值字段 `bpm`（30–300）与可选的 `beat_offset_seconds`。只读，不自动改写文件；在原有 JSON 对象内添加字段，保留其他信息。
- 没有 BPM 字段时，单个后台任务分析该目录的 `song.wav`，不播放音频，不调用 Unity。支持 RIFF PCM 8/16/24/32 位及 float32；分析最多前 120 秒、64 MiB。
- 用能量新颖度、自相关和拍点相位估计固定 BPM，显示估计来源与置信度。静音、过短、格式异常或低置信度时明确显示待就绪，不伪造 120 BPM。
- 音频估计存在半速/倍速、切分节奏、弱起与变速歌曲误差。需要精确拍点时，填写元数据并在曲库点击“重新加载当前曲目”。例如 `"bpm": 128, "beat_offset_seconds": 0.25` 表示源音频首拍在 0.25 秒。
- 切曲、清空、源文件变化和重新加载都会使旧身份失效；后台旧结果不会用于新曲。该实现不新增依赖，不访问模型或录制素材。

这不是通用变速歌曲的全曲 beat-tracking；外部歌曲目前是一个固定 BPM 加首拍偏移。原生模板自身的变速 BPM 则由客户端 BPM 曲线参与映射。

## 时间映射

1. 通过已有音频轨的速度和延迟，将播放器绝对时间换算成**源音频秒数**。
2. 加上 UI“灯光拍点偏移”（正值使灯光提前），减去首拍偏移，按曲目 BPM 换算成拍数；首拍前固定为第 0 拍。
3. 通用模式直接以拍数驱动既有程序化周期。
4. 原生模式将模板原生 `CampusBpmInfo.EvaluateBpmAtTime(float)` 曲线以 8 Hz 数值积分成拍数表，再反解当前拍数对应的模板秒数，驱动自有手动图。长曲按模板总拍数循环，不用模板原曲的同一秒数硬套。

例如：源音频 90 BPM、首拍 1 秒，当前源音频时间 5 秒对应第 6 拍；120 BPM 模板应采样第 3 秒，而不是第 5 秒。暂停重采样同一时刻，前后跳转直接重算；停止或作用域失效走已有恢复账本。

**BPM 决定节奏，不包含灯色、设备 ID、舞台结构、段落或副歌语义。**原生模板仍须匹配舞台；拍数适配不等于为任意外部歌曲还原游戏专属 MV 编排。源模板中原本未按 BPM 编排的时间效果也会整体重定时。

## 原生目录修复

- 原生字符串使用 `il2cpp_string_length/chars`，数组使用导出的头部/元素尺寸，不依赖猜测的对象内存偏移。
- Master 提供环境与时间轴 ID，逐项调用原生 Octo 资源查询器确定实际名称；全局名称枚举仅作诊断，不再作为配对的唯一门槛。
- 日志记录记录数、有效 ID、舞台、时间轴、配对及歧义计数。失败保留有效旧目录，仍校验依赖缓存，不新增下载或安装器修改。
- 原生接口签名、nullable bool 布局及对象身份继续精确校验；元数据匹配不替代真实客户端运行验证。

## 验证与交付边界

合成输入覆盖 BPM 检测、WAV 解码、元数据优先级、切曲身份、音频变速/延迟、原生变速积分、暂停、跳转和循环。ImGui 交互覆盖自动模板不改变播放曲目、显示当前曲目/BPM，以及不依赖模板目录的通用模式。

使用 `build.ps1` 构建 Runtime、NativeAOT 和 Contracts，运行现有核心、GUI、布局、Unicode 及导入桥回归；结果分别记录在 `build/validation/library-tempo/`。测试不读取用户音频、模型或动作，不启动游戏。部署仅替换经用户同意的插件 DLL 并保存回滚副本。

真实摄影载入、原生目录配对、各舞台设备覆盖及游戏内灯效视觉验收单独记录；本地构建和合成测试不作为这些运行效果已通过的证明。
