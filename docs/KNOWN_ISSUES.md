# 已知问题

GakuMotion 当前处于**技术预览阶段（Developer / Technical Preview）**。  
本文档列出了目前已知的系统局限与兼容性边界，并非所有可能遇到问题的完整穷尽清单。

---

## 动作重定向与回放
- **动作质量**：动作最终表现部分取决于原始 VMD 文件的质量。源动作自带的滑步、重心不稳或抖动等缺陷，在导入重定向后依然会保留。
- **制作规范差异**：源模型的骨骼结构与作者制作规范的差异，可能会导致不同动作的重定向效果存在偏差。
- **手指与手掌匹配**：部分动作的手掌、大拇指与手指姿态可能无法 100% 完美贴合目标角色的默认骨骼形态。
- **角色体态自适应**：针对不同角色特有的体型与身高，自适应算法仍在持续迭代中。

## 资源导入
- **VMD 兼容性**：极少数特殊编码或结构异常的 VMD 文件可能无法生成预期效果。
- **面部与镜头支持**：表情、眼动与镜头运镜的支持程度取决于输入数据格式及当前已支持的转换链路。镜头目前尚不支持自动对焦。需特别说明：眼动转换链路目前尚未达到预期效果，正在持续迭代中。
- **相机根节点**：在部分动作与相机的特定组合下，可能无法自动注册相机根节点（Camera Root）。在自动模式下，原始相机数据仍可导入，但可能未完成根节点对齐。
- **音频格式**：暂不支持非 PCM 或非标音频格式，导入前需先将音频转换为兼容的标准 PCM WAV 格式。

## 运行时与次级物理
- **物理表现差异**：游戏原生的次级物理解算（头发、裙摆、配饰等）在不同角色、不同服装与不同场景光照下可能存在行为差异。
- **边界解算瑕疵**：某些极限姿态下可能会出现轻微滑步、模型穿模或反向动力学（IK）目标无法触达等现象。
- **场景支持限制**：并非游戏内的所有场景都已完整开放支持自定义演出回放。
- **实验舞台与灯光**：16 个摄影替换入口仍需逐项确认本地资源和实际画面；程序化染色、呼吸与渐变不等于 Agitato 等歌曲的原生演出时间轴。详见[舞台与灯光](STAGE_LIGHTING.md)。

## VR 兼容性 (VR)
- **交互**：支持 VR 视角观看并不代表包含专门的原生 VR 操作与编辑界面。
- **运镜与眩晕感知**：VR 空间下的运镜体验与舒适度可能与桌面端屏幕回放存在明显差异。
- **操作映射**：部分桌面端的快捷键与控制功能在 VR 模式下可能不可用。

## 通用说明 (General)
- **架构变更**：在 1.0 正式版发布前，预览版的 API 定义、数据接口与配置文件格式仍可能发生变更。
- **数据安全**：在安装或覆盖新构建版本（Build）前，建议手动备份现有的个人配置与用户数据。

## 问题反馈 (Reporting an Issue)

如遇 Bug 或异常，提交反馈时请务必提供以下信息：
- GakuMotion 插件版本
- GakuLoader 宿主版本
- 游戏本体版本（如已知）
- 详细的问题复现步骤
- 预期表现与实际异常表现

切勿在公开 Issue 中上传任何受版权保护的游戏本体资产、个人账号私密数据或未经许可授权的模型与工程文件。

- **缺陷汇报**：请前往本仓库的 **GitHub Issues** 提交。
- **疑问探讨与想法交流**：欢迎前往 **GitHub Discussions** 讨论区发帖。
